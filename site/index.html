  • macOS: сборка без подписи Apple. При первом запуске откройте приложение через правый клик → «Открыть». Если macOS пишет, что приложение «повреждено», выполните в Терминале: xattr -cr "/Applications/Nami.app"
  • Windows: SmartScreen может предупредить. Нажмите «Подробнее» → «Выполнить в любом случае».

Расширение Nami Collector

  1. Откройте в Nami раздел Настройки и скачайте архив расширения.
  2. Распакуйте архив. В Chrome откройте chrome://extensions.
  3. Включите Режим разработчика и выберите Загрузить распакованное.
  4. В popup расширения нажмите Подключить к приложению.
