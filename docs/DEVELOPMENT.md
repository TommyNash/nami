# Разработка интерфейса

## Куда класть код

| Задача | Куда |
|---|---|
| Новая страница | `renderer/js/pages/<имя>.js`, функция в `FoundersPages`, скрипт в `index.html` до `app.js` |
| Разметка экрана | соседний `*-view.js`, без запросов |
| Расчёт без DOM | `renderer/js/model/` |
| Вызов Rust | метод в `NamiServices`, команда уже есть в `tauri-bridge.js` |
| Ключ настройки | `NamiStore`, имя `fa.*` не менять |
| Общая карточка / пустое состояние | `renderer/js/ui/` |
| Текст | `renderer/locales/*.json` и `T()` |

Страница не вызывает `invoke` и не пишет `localStorage` напрямую.

## Жизненный цикл

`app.js` → `render`. При смене раздела вызывается `NamiLifecycle.destroy(старый)`. Подписку, которую надо снять, регистрируйте через `NamiLifecycle.on(page, fn)`.

Скелетон только при входе в раздел. Фильтр обновляет существующие узлы (`patchGamesView`, `patchKpiCard`).

## Проверки

```bash
npm test
npm run typecheck
```

`npm test` — текущее поведение долей, свечей, сравнения и кэша. После правки `model/` тест должен остаться зелёным или вы сознательно меняете поведение.
