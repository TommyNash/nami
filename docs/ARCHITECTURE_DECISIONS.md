# Решения по фронтенду

Дата: 2026-11-22. До этапа 2 рефакторинга.

## ADR-1. Без Vite

Сборка остаётся как есть: `frontendDist: ../renderer`, `npm start` → `scripts/tauri.sh dev`, скрипты в `index.html` без бандлера.

Vite потребует `beforeDevCommand`, смену `frontendDist` и перевод ~20 глобальных скриптов на ES modules до того, как страницы разделены. Это ломает текущий запуск и сборку dmg/exe ради инструмента, который здесь не нужен.

Шаблоны: `<template>` в `renderer/templates/*.html`. Подключение один раз при старте, не на смене фильтра и не через `fetch` в горячем пути. Мелкие куски — функции, которые возвращают DOM (`textContent` / `setAttribute`). Своего шаблонизатора нет.

## ADR-2. Скрипты остаются классическими

Порядок `<script>` в `index.html` — контракт. `import`/`export` и Vite не включаем: это отдельная смена сборки.

Публичные интерфейсы: `window.NamiStore`, `window.NamiServices`, `window.NamiLifecycle`, `window.NamiData`. Внутренние значения — `const` или `let`. Они видны следующим классическим скриптам и не висят на `window`. `var` для этой видимости не нужен.

## ADR-2b. Шаблоны

Проверены разметки портфеля, карточки, налогов и настроек. В каждой есть подставленные значения или повтор строк. Статический `<template>` их не заменяет без шага подстановки, а свой шаблонизатор не вводим. Мелкие куски — функции DOM (`namiEl`, `namiEmpty`).

## ADR-3. Слои только там, где файл смешивает обязанности

Полный набор page/controller/service/model/view — для `games.js` (2372), `workspace.js` (1166), `charts.js` (1959). Settings, tax, compare — 2–3 файла. Общие компоненты — только то, что уже повторяется (KPI, период, пустое состояние, скелетон).

## ADR-4. Состояние

Глобально: страница, период, аккаунт, выбранная игра, compareIds, настройки, которые уже лежат в `localStorage` под ключами `fa.*`. Имена и формат ключей не меняются.

Локально у экрана: поиск, сортировка, раскрытые меню, ховер. Их можно писать в `state` напрямую: Proxy не сохраняет эти поля.

Сохраняемые поля (страница, период, аккаунт, сравнение, метрики карты) при присваивании в `state` проходят через методы store. `fa.lang` пишет `i18n.js`: переводчик выполняется раньше store. Ключи онбординга — `nami.onboarded`, не `fa.*`.

## ADR-5. Tauri только из сервисов

`window.foundersApi` остаётся единственной обёрткой IPC (`tauri-bridge.js`). Страницы и компоненты его не вызывают: только `*.service.js`. Команды Rust не дублируются и не переименовываются.

## ADR-6. innerHTML

Новый код не вставляет названия игр, ответы кабинета и импорт через `innerHTML`. Существующие вставки убираются в том этапе, который трогает файл. Статический HTML скелетона без пользовательских данных можно оставить до переноса экрана.
