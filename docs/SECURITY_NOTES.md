# Заметки по безопасности интерфейса

Дата: 2026-11-22.

## CSP

`src-tauri/tauri.conf.json`: `default-src 'self'`, стили и скрипты с `'unsafe-inline'` (инлайн-стили и скрипт сплэша), картинки `self`, `data:` и аватары Яндекса, `connect-src` только IPC. Внешние скрипты не подключаются. Расширять CSP не нужно.

## innerHTML

Новые пустые и ошибочные состояния (`namiEmpty`) пишут текст через `textContent`.

В страницах остаются строки разметки. Названия игр в сравнении и чипах проходят через `FoundersFormat.esc`. Карточка KPI по-прежнему кладёт готовый `sub` в `innerHTML` — это локальная вёрстка свечей, не сырой ответ кабинета. Сырые поля игр в новые строки так не добавлять.

## IPC

Экраны ходят в `NamiServices`. `invoke` только в `tauri-bridge.js`.
