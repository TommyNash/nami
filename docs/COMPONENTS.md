# Компоненты

Общие куски лежат в `renderer/js/ui/` и не знают про страницу.

- `namiEl(tag, attrs, text)` — элемент, текст только через `textContent`.
- `namiEmpty(message)` — блок `.empty`.
- `patchKpiCard(card, { label, value, fmt, digits, sub })` — обновляет карточку на месте, не пересоздаёт её.

Новый компонент — функция в `ui/`, если её используют два экрана. Параметров минимум. Разметка одного экрана — `pages/<экран>-view.js`. Она возвращает HTML, обработчики остаются в файле раздела.

Не вставляйте названия игр и ответы кабинета через `innerHTML`. Для них `textContent` или `FoundersFormat.esc`, если строка уже собрана.
